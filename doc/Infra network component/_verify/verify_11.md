# verify_11 (11장 Docker 방화벽)
원천: docker-fundamental/16 (16.1~16.4+실습), 15.1(netns DNAT), 18.4
- 확인한 절: 16.1, 16.2, 16.3, 16.4, 실습, 15.1, 18.4
- 수정 4건
  1. 체크리스트 "Engine 28 이후에서도 게시된 포트는 ufw보다 Docker 규칙이 먼저임을 전제로" -> 원천에 근거 없는 단정. 28.0.0은 "게시하지 않은 포트" 차단만 한다고 고치고, 게시 포트와 ufw 관계는 별도 확인하라고 수정
  2. 코어 2 말미 [보충] ("게시된 포트에 대해 ufw보다 Docker 규칙이 먼저") -> 같은 이유로 "원천은 28.0.0이 허점 2까지 해소했다고 말하지 않는다"로 교체
  3. 3.2 다이어그램의 "table inet ...(firewalld/관리자 소유)" -> firewalld가 inet 테이블을 쓴다는 근거 없음. "table ... (firewalld/관리자가 만든 다른 테이블)"로 수정
  4. 4.2(IPv6와 방화벽)의 근거가 18.4인데 원문 근거 줄에 누락 -> 18.4 추가 (내용은 18.4와 일치 확인)
- 삭제 0건
- 남은 불확실성: 시나리오 1의 "Docker 버전 27.x"는 시나리오 설정값(원천 사실 아님). 허점 2가 28.0.0 이후에도 남는지는 원천이 명시하지 않아 단정하지 않음.
