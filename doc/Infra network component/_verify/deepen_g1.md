# deepen_g1 (심화 책 0부/01, 1부/02·03·04 — 입문 책 중복을 심화로 교체)

대조 입문 장: 1장(인프라 전체 그림), 4장(네트워크 기초), 6장(네임스페이스), 15장(Pod), 그리고 중복 판정에 필요해 함께 읽은 11장(Docker 네트워크)·21장(네트워크 모델·Service)·23장(Ingress). 입문 책은 수정하지 않았다.

공통: 중복 절은 "> **입문 책에서 배운 것:**" 복습 줄 + 입문 책 링크로 줄이고, 그 자리를 원천의 더 깊은 절로 채웠다. 링크 존재·`<details>` 짝·표 앞 빈 줄·물결표 점검은 스크립트로 통과(링크 깨짐 0, details 짝 12/13/11/12).

## 1장. 패킷 한 개의 여정 (0부/01) — 바뀐 절 7
입문 1장은 Terraform·EKS 배포 흐름이라 직접 중복은 거의 없고, 실제 중복은 입문 11·21·23장과 났다. 이 장은 책 전체 "지도"라서 지도 구조(1.1, 1.3 표, 2.3, 2.4, 3.1, 3.2, 4.4)는 그대로 두었다.

| 절 | 판정 | 교체 내용 · 새 원천 |

| 코어 4 문장 | 입문 21장 코어 2·4와 같은 말 | 규칙 구조(`KUBE-SVC` 확률 선택, `0x4000` 마크 SNAT, Ingress 자체 프록시 상태)로 재작성 |
| 1.2 컨테이너 안 | 중복(입문 6장) | 복습 줄 + 3장 안내로 축소 |
| 1.4 들어오는 길 | 부분 중복 | docker 12.6의 실제 DNAT 규칙·`PREROUTING`/`OUTPUT` 두 체인 점프 추가 |
| 2.1 네 가지 요구사항 | 중복(입문 21장 1.2) | 복습 줄 + 13장 안내로 축소 |
| 2.2 IP 대역 3 | 중복(입문 21장 1.4) | 표 → 복습 줄, 노드 수 계산식(`2^(24-16)=256`, `--max-pods` 110) 추가 (k8s 13.5) |

## 4장. veth·브리지·라우팅·ARP (1부/04) — 바뀐 절 5

| 절 | 판정 | 교체 내용 · 새 원천 |

## 메모
- 사실은 모두 위 원천 파일을 읽고 썼다. 원천 문장 사이를 잇는 해석 한 군데(pause.c 핸들러 ↔ PID 1 시그널)는 [보충]으로 표시했다. "실행 검증됨"이라 쓴 곳 없음.
- 분량이 줄지 않고 늘었다(총 +23KB). 중복 제거로 줄인 만큼보다 이전 판이 범위 밖으로 뺀 원천 절(2장 6.4·6.5·6.6 등)을 들인 양이 커서다. 줄이려면 2장 인출 질문·3장 4.3 JSON이 후보.
- 학습 가이드(`00-학습-가이드/`)는 건드리지 않았다. 동기화가 필요한 코어 문구: 1장 코어 4, 2장 코어 3·4 문구(코어 구조 변경), 3장 코어 1~4, 4장 코어 1·3.
