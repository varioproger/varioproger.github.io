## FC: 00-학습-가이드/플래시카드.md
- 방법: 23개 장 본문(각 장 파일)과 카드 445장(질문+답)을 장 단위로 전부 대조. 장 전체를 읽은 경우 외에도 카드 근거가 되는 절(코어 본문, 시나리오, 표)을 확인. 확인한 장 23개.
- 사실 오류로 수정한 카드: 0장. 본문에 근거 없어 삭제한 카드: 0장. [보충]으로 바꾼 카드: 0장 (카드는 [보충] 블록이 없는 형식).
- 총 장수 445장(머리말) = 본문 카드 445 = Anki 블록 445 (장별 19,19,19,19,18,19,20,20,18,20,20,20,20,20,20,19,20,20,20,17,19,19,20 합 445). 일치.
- 서식 수정: 산문의 물결표 `~`를 `&#126;`로 변경 (머리말 "장당 12~20장", 카드 4장: 에페머럴 포트 32768~60999, NodePort 30000~32767, 사이드카 1~3ms·50~100MB, 임시 포트 점검). Anki 가져오기 블록은 평문 `~` 유지(스크립트로 재생성).
- `<details>` 445/445 짝 일치. 본문 상대 링크 전부 존재.
- 본문 대조에서 확인한 주의 지점(수정 불필요): 8장 카드(게시 포트는 호스트 방화벽보다 Docker 규칙이 먼저)와 11장 [보충](28.0.0은 FORWARD 순서 문제를 해결했다고 하지 않음)은 모순 없음. 7장 카드 18(CNI "ADD/DEL 두 개의 커맨드에 가까운 단순 인터페이스")은 14장의 4동작과 카드 간 표현 차이이나 7장 본문과 일치하므로 유지.

## 남은 불확실성
- 카드가 근거로 삼는 장 본문의 원천 일치 여부(예: 12장 Docker 29.5 기본 백엔드 변경, 20장 네이티브 사이드카 버전, 17장 IPVS 폐기 일정)는 본문 검증 담당 영역이며 이 검증은 카드↔본문 일치만 확인함.
- 플래시카드 본문 카드(main)와 Anki 블록은 `~`/`&#126;` 표기만 의도적으로 다름.
