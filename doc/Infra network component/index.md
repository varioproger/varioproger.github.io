# Linux + Docker + Kubernetes 네트워크의 구성 요소와 방식 — 필수 이론 지식

컨테이너 하나가 보낸 패킷이 **리눅스 커널 → Docker → 쿠버네티스**의 어떤 부품을 지나 목적지에 닿는지, 각 부품이 **왜 그렇게 동작하는지**를 이해하기 위한 이론서입니다. 명령어 모음집이 아니라 "장애가 났을 때 어느 부품을 의심해야 하는가"를 판단하는 힘을 기르는 데 맞췄습니다.

## 이 책이 만들어진 방식

1. 참고 자료 폴더(`D:\reference\doc`)의 모든 책 목차를 확인했습니다.
2. "네트워크 구성 요소와 방식을 이해하는 데 필수인가"를 기준으로 절·장 단위로 판단했습니다. → [필수 목차 리스트](00_필수_목차_리스트.md)
3. 선별한 목차를 하나의 책으로 묶고, 각 장을 원문 내용과 대조해 집필했습니다.
4. 집필 방식은 두 학습법 가이드(통합 암기법 마스터 가이드, 효율적인 공부법 통합 완벽 가이드)를 따랐습니다. 공부 방법은 [📚 학습 가이드](00-학습-가이드/index.md)에 있습니다.

> **표기 규칙** — 본문 중 `> **[보충]**`으로 시작하는 인용 블록은 원문 자료에 직접 근거가 없는 입문자용 보충 설명입니다. 그 외 본문은 원문에서 가져온 내용입니다. 각 장 맨 끝에 원문 근거 파일을 적었습니다.
