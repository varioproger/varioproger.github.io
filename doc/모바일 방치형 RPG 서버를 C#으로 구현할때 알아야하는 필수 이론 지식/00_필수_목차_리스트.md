# 필수 이론 서적 목차 리스트 v3 (모바일 방치형 RPG **서버** × C# 입문자)

> 전제: C#으로 **HTTP 웹 백엔드(게임 서버)** 를 만든다. 모바일 클라이언트(Unity 등)는 이 서버의 API를 호출한다.
> v1은 클라이언트 관점으로 선별했으나, 서버 개발로 확정되어 웹 서버·DB·인증 책을 채택으로 바꾸고 부를 추가했다.

## 2. 필수 목차

### 제1부~제7부 (C# 언어와 공통 기반) — 작성·검증 완료, 서버 관점으로 재조정
1. C# 문법 기초 / 2. 객체지향 / 3. 델리게이트·예외·현대 C# / 4. .NET 기본 라이브러리 (문자열, **날짜·시간(UTC)**, TimeProvider·일일 초기화(v3), BigInteger, Random.Shared·가중치 뽑기(v3), 컬렉션, LINQ, JSON) / 5. 메모리와 성능 기초 / 6. 비동기와 시간 흐름 / 7. 설계 원칙과 패턴(DI, Options 포함)

### 제8부. 웹 API 기초 — B12 1-3장, B1 2-7장
1. 웹 API와 HTTP: 요청/응답, 메서드, 상태 코드 (B12 Ch1, B9 Ch1·4)
2. REST API 설계: 리소스, URL, HTTP 메서드 매핑, 응답 코드 (B12 Ch1, B9 Ch4)
3. ASP.NET Core 프로젝트 만들기·실행·Swagger (B12 Ch2, B1 Ch3)
4. Minimal API와 컨트롤러 기반 API의 기본 (B12 Ch2, B9 Ch5·6, B1 Ch5·20)
5. 라우팅 (B12 Ch3, B1 Ch6)
6. 모델 바인딩과 검증 (B12 Ch3, B1 Ch7)
7. DTO 패턴과 API 계약 (B9 Ch4)
8. JSON 직렬화 설정 (B12 Ch15, B9 Ch5)
9. 실시간 API 개요: 폴링 vs 실시간 (B12 Ch1, 개요만)

### 제9부. ASP.NET Core 핵심 동작 — B1 4·8~10장, B12 3·4·16장
1. 요청 처리 흐름과 미들웨어 파이프라인 (B1 Ch4, B12 Ch4)
2. 의존성 주입 등록과 수명(Singleton/Scoped/Transient) (B1 Ch8·9, B12 Ch2, B9 Ch8)
3. 설정: appsettings.json, 환경, 옵션 패턴 (B1 Ch10, B12 Ch3, B9 Ch9)
4. 로깅 (B12 Ch4, B9 Ch10, B1 Ch26)
5. 예외 처리와 오류 응답 (B12 Ch16)
6. 헬스 체크 (B12 Ch16)

### 제10부. 데이터 접근 (EF Core) — B5 1-5장, B12 5-7장, B1 12장
1. ORM과 EF Core 개념, DbContext (B5 Ch1, B12 Ch5)
2. 엔티티 모델과 매핑(규칙, 어노테이션, Fluent API) (B12 Ch5, B5 Ch2)
3. 조회: LINQ 쿼리, 필터·정렬·페이징, 관련 데이터 로딩 (B5 Ch2, B12 Ch5)
4. 생성·수정·삭제와 엔티티 상태 (B5 Ch3, B12 Ch5)
5. 관계: 일대다, 일대일, 다대다 (B12 Ch6, B5 Ch3)
6. 비즈니스 로직과 DB 코드 분리 (B5 Ch4)
7. 웹 앱에서 DbContext: DI 등록, 수명, async (B5 Ch5, B12 Ch7)
8. 동시성 충돌 (재화·아이템 동시 수정) (B12 Ch7)
9. 트랜잭션 (B5 Ch4)
10. 마이그레이션 (B5 Ch5)
11. 추적 vs 비추적 쿼리, IQueryable, 일괄 업데이트 (B12 Ch7)
12. 중복 요청 방지: 멱등성 키와 유니크 제약 (v3 보강, doc)

### 제11부. 인증과 보안 기초 — B12 8장, B1 23~25·29장
1. 인증과 인가의 차이 (B12 Ch8, B1 Ch24)
2. JWT 구조와 API 인증 (B12 Ch8, B1 Ch25)
3. 역할·정책 기반 인가 (B12 Ch8, B1 Ch24)
4. HTTPS와 기본 보안 위협 (B12 Ch15, B1 Ch28·29) + 요청 속도 제한 (v3 보강, doc)

### 제12부. 백그라운드 서비스·캐시·외부 호출 — B1 33·34장, B12 15장, B8
1. BackgroundService/IHostedService로 주기 작업 실행 (B1 Ch34)
2. 스코프가 있는 서비스를 백그라운드에서 쓰기 (B1 Ch34, B5 Ch5)
3. 캐싱: 메모리, 분산, 응답, 출력 캐시 (B12 Ch15)
4. HttpClientFactory (B1 Ch33, B12 Ch15) + 타임아웃·재시도·서킷 브레이커 (v3 보강, doc)
5. 페이지네이션 (B12 Ch15)
6. 비동기 코드 취소와 서비스 종료 (B8 Ch10, B1 Ch34)

### 제13부. 아키텍처·테스트·배포 기초 — B2, B9 2·14장, B12 9·10·14장
1. 웹 앱 아키텍처: 모놀리식, 계층, Clean Architecture (B2, B9 Ch14, B12 Ch17)
2. 자동화 테스트 개요, 단위 테스트(xUnit) (B9 Ch2, B12 Ch9, B1 Ch35)
3. 통합 테스트(WebApplicationFactory) (B12 Ch10, B9 Ch2, B1 Ch36)
4. Docker 컨테이너 기본과 CI/CD 개요 (B12 Ch14, B2)

### v3 보강 — doc 폴더 문서 대조로 추가 (11권 밖, 본문에 `📚 참고(doc, 책 외)`로 표시)

| 제12부 12.4 끝 | 타임아웃·재시도·서킷 브레이커(`AddStandardResilienceHandler`) | 결제 검증 등 외부 호출 실패 대비, 재시도와 멱등성의 관계 | C# Complete Guide 43·51장, Node.js Complete Guide 29.6 |
