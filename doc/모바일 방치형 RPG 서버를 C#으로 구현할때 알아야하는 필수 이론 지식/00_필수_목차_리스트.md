# 필수 이론 서적 목차 리스트 v3 (모바일 방치형 RPG **서버** × C# 입문자)

> 📌 **재구성 안내:** 이 목차 리스트는 책을 처음 기획할 때의 선정 기록입니다. 이후 부 순서를 바꿨습니다(메모리와 성능 → 제3부, 웹 API 기초 → 제7부, ASP.NET Core → 제8부, 설계 원칙과 패턴 → 제9부). 부 번호는 새 순서로 고쳤지만, "2-3", "12절" 같은 **절 번호는 재구성 전 기준**이라 본문 절 번호와 다를 수 있습니다.

> 전제: C#으로 **HTTP 웹 백엔드(게임 서버)** 를 만든다. 모바일 클라이언트(Unity 등)는 이 서버의 API를 호출한다.
> v1은 클라이언트 관점으로 선별했으나, 서버 개발로 확정되어 웹 서버·DB·인증 책을 채택으로 바꾸고 부를 추가했다.

## 2. 필수 목차

### 제1부~제9부 (C# 언어와 공통 기반) — 작성·검증 완료, 서버 관점으로 재조정
1. C# 문법 기초 / 2. 객체지향 / 3. 델리게이트·예외·현대 C# / 4. .NET 기본 라이브러리 (문자열, **날짜·시간(UTC)**, TimeProvider·일일 초기화(v3), BigInteger, Random.Shared·가중치 뽑기(v3), 컬렉션, LINQ, JSON) / 5. 메모리와 성능 기초 / 6. 비동기와 시간 흐름 / 7. 설계 원칙과 패턴(DI, Options 포함)

### 제7부. 웹 API 기초 — Web API Development with ASP.NET Core 8 1-3장, ASP.NET Core in Action 2-7장
1. 웹 API와 HTTP: 요청/응답, 메서드, 상태 코드 (Web API Development with ASP.NET Core 8 Ch1, Architecting ASP.NET Core Applications Ch1·4)
2. REST API 설계: 리소스, URL, HTTP 메서드 매핑, 응답 코드 (Web API Development with ASP.NET Core 8 Ch1, Architecting ASP.NET Core Applications Ch4)
3. ASP.NET Core 프로젝트 만들기·실행·Swagger (Web API Development with ASP.NET Core 8 Ch2, ASP.NET Core in Action Ch3)
4. Minimal API와 컨트롤러 기반 API의 기본 (Web API Development with ASP.NET Core 8 Ch2, Architecting ASP.NET Core Applications Ch5·6, ASP.NET Core in Action Ch5·20)
5. 라우팅 (Web API Development with ASP.NET Core 8 Ch3, ASP.NET Core in Action Ch6)
6. 모델 바인딩과 검증 (Web API Development with ASP.NET Core 8 Ch3, ASP.NET Core in Action Ch7)
7. DTO 패턴과 API 계약 (Architecting ASP.NET Core Applications Ch4)
8. JSON 직렬화 설정 (Web API Development with ASP.NET Core 8 Ch15, Architecting ASP.NET Core Applications Ch5)
9. 실시간 API 개요: 폴링 vs 실시간 (Web API Development with ASP.NET Core 8 Ch1, 개요만)

### 제8부. ASP.NET Core 핵심 동작 — ASP.NET Core in Action 4·8~10장, Web API Development with ASP.NET Core 8 3·4·16장
1. 요청 처리 흐름과 미들웨어 파이프라인 (ASP.NET Core in Action Ch4, Web API Development with ASP.NET Core 8 Ch4)
2. 의존성 주입 등록과 수명(Singleton/Scoped/Transient) (ASP.NET Core in Action Ch8·9, Web API Development with ASP.NET Core 8 Ch2, Architecting ASP.NET Core Applications Ch8)
3. 설정: appsettings.json, 환경, 옵션 패턴 (ASP.NET Core in Action Ch10, Web API Development with ASP.NET Core 8 Ch3, Architecting ASP.NET Core Applications Ch9)
4. 로깅 (Web API Development with ASP.NET Core 8 Ch4, Architecting ASP.NET Core Applications Ch10, ASP.NET Core in Action Ch26)
5. 예외 처리와 오류 응답 (Web API Development with ASP.NET Core 8 Ch16)
6. 헬스 체크 (Web API Development with ASP.NET Core 8 Ch16)

### 제10부. 데이터 접근 (EF Core) — Entity Framework Core in Action 1-5장, Web API Development with ASP.NET Core 8 5-7장, ASP.NET Core in Action 12장
1. ORM과 EF Core 개념, DbContext (Entity Framework Core in Action Ch1, Web API Development with ASP.NET Core 8 Ch5)
2. 엔티티 모델과 매핑(규칙, 어노테이션, Fluent API) (Web API Development with ASP.NET Core 8 Ch5, Entity Framework Core in Action Ch2)
3. 조회: LINQ 쿼리, 필터·정렬·페이징, 관련 데이터 로딩 (Entity Framework Core in Action Ch2, Web API Development with ASP.NET Core 8 Ch5)
4. 생성·수정·삭제와 엔티티 상태 (Entity Framework Core in Action Ch3, Web API Development with ASP.NET Core 8 Ch5)
5. 관계: 일대다, 일대일, 다대다 (Web API Development with ASP.NET Core 8 Ch6, Entity Framework Core in Action Ch3)
6. 비즈니스 로직과 DB 코드 분리 (Entity Framework Core in Action Ch4)
7. 웹 앱에서 DbContext: DI 등록, 수명, async (Entity Framework Core in Action Ch5, Web API Development with ASP.NET Core 8 Ch7)
8. 동시성 충돌 (재화·아이템 동시 수정) (Web API Development with ASP.NET Core 8 Ch7)
9. 트랜잭션 (Entity Framework Core in Action Ch4)
10. 마이그레이션 (Entity Framework Core in Action Ch5)
11. 추적 vs 비추적 쿼리, IQueryable, 일괄 업데이트 (Web API Development with ASP.NET Core 8 Ch7)
12. 중복 요청 방지: 멱등성 키와 유니크 제약 (v3 보강, doc)

### 제11부. 인증과 보안 기초 — Web API Development with ASP.NET Core 8 8장, ASP.NET Core in Action 23~25·29장
1. 인증과 인가의 차이 (Web API Development with ASP.NET Core 8 Ch8, ASP.NET Core in Action Ch24)
2. JWT 구조와 API 인증 (Web API Development with ASP.NET Core 8 Ch8, ASP.NET Core in Action Ch25)
3. 역할·정책 기반 인가 (Web API Development with ASP.NET Core 8 Ch8, ASP.NET Core in Action Ch24)
4. HTTPS와 기본 보안 위협 (Web API Development with ASP.NET Core 8 Ch15, ASP.NET Core in Action Ch28·29) + 요청 속도 제한 (v3 보강, doc)

### 제12부. 백그라운드 서비스·캐시·외부 호출 — ASP.NET Core in Action 33·34장, Web API Development with ASP.NET Core 8 15장, Concurrency in C# Cookbook
1. BackgroundService/IHostedService로 주기 작업 실행 (ASP.NET Core in Action Ch34)
2. 스코프가 있는 서비스를 백그라운드에서 쓰기 (ASP.NET Core in Action Ch34, Entity Framework Core in Action Ch5)
3. 캐싱: 메모리, 분산, 응답, 출력 캐시 (Web API Development with ASP.NET Core 8 Ch15)
4. HttpClientFactory (ASP.NET Core in Action Ch33, Web API Development with ASP.NET Core 8 Ch15) + 타임아웃·재시도·서킷 브레이커 (v3 보강, doc)
5. 페이지네이션 (Web API Development with ASP.NET Core 8 Ch15)
6. 비동기 코드 취소와 서비스 종료 (Concurrency in C# Cookbook Ch10, ASP.NET Core in Action Ch34)

### 제13부. 아키텍처·테스트·배포 기초 — Architecting Modern Web Applications with ASP.NET Core and Azure, Architecting ASP.NET Core Applications 2·14장, Web API Development with ASP.NET Core 8 9·10·14장
1. 웹 앱 아키텍처: 모놀리식, 계층, Clean Architecture (Architecting Modern Web Applications with ASP.NET Core and Azure, Architecting ASP.NET Core Applications Ch14, Web API Development with ASP.NET Core 8 Ch17)
2. 자동화 테스트 개요, 단위 테스트(xUnit) (Architecting ASP.NET Core Applications Ch2, Web API Development with ASP.NET Core 8 Ch9, ASP.NET Core in Action Ch35)
3. 통합 테스트(WebApplicationFactory) (Web API Development with ASP.NET Core 8 Ch10, Architecting ASP.NET Core Applications Ch2, ASP.NET Core in Action Ch36)
4. Docker 컨테이너 기본과 CI/CD 개요 (Web API Development with ASP.NET Core 8 Ch14, Architecting Modern Web Applications with ASP.NET Core and Azure)
