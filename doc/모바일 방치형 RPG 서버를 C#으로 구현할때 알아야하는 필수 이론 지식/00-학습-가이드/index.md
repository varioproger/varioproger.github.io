# 📚 학습 가이드 — C# 서버

이 책을 **읽고 끝나는 책**이 아니라 **기억에 남는 책**으로 쓰기 위한 페이지입니다. 공통 원리는 [이 문서로 공부하는 법](/doc/how-to-study/)에 있습니다.

| 페이지 | 용도 |
|---|---|
| [코어 노트](코어-노트.md) | 결정적 지식 3개 + 장별 한 문장. 시작 전 한 번, 매주 복습 |
| [플래시카드](플래시카드.md) | 364장. 매일 10~15분, Anki로 옮기기 가능 |
| [복습 계획표](복습-계획표.md) | 10분·1일·1주·1달 체크 |

## 추천 진행 순서

1. **코어 노트**를 5~15분 훑어 책 전체의 지도를 먼저 만든다.
2. 한 부씩: 🧭 읽기 전에 → 스킵 읽기 → 정독(여백 누적 요약) → 🧠 인출 연습.
3. 그날 끝낸 장을 **복습 계획표**에 적고, 다음 날부터 간격 반복.
4. 인출 질문을 다 맞히면 그 장의 카드는 Anki에만 남긴다.
5. 한 부를 끝낼 때마다 코어 노트의 결정적 지식으로 돌아가, 그 부의 내용이 어떻게 거기서 파생되는지 말로 설명해 본다.
