# Linux·Docker·Kubernetes OS 구성 요소 필수 이론

**"컨테이너와 쿠버네티스는 결국 리눅스 커널 기능 위의 프로세스다"** — 이 사슬을 끝까지 따라가며, Linux·Docker·Kubernetes의 구성 요소가 무엇이고 어떻게 맞물려 동작하는지 이해하기 위한 이론서입니다. 명령어 사용법이 아니라 **구성 요소와 동작 방식**을 다룹니다.

## 이 책이 만들어진 방식

1. 참고 자료 폴더 중 Linux·Docker·Kubernetes 구성 요소를 다루는 책을 찾았습니다. (`linux`, `docker-fundamental`, `Kubernetes_Internals_Network_Guide`, `kubernetes-textbook-main`, `kubernetes-qustion-book`)
2. 모든 책의 목차를 확인하고 "구성 요소와 동작 방식을 이해하는 데 필수인가"로 판단했습니다. 선별 결과와 제외 사유는 [필수 목차 리스트](00-필수-목차-리스트.md)에 있습니다.
3. 선별한 목차를 하나의 31장 목차로 묶고, 각 장을 원문을 읽고 그 내용에 근거해 집필했습니다. 원문에 없는 보충은 `> **[보충]**` 인용 블록으로 구분하고, 각 장 끝에 `📖 출처`를 남겼습니다.
4. 집필은 「통합 암기법 마스터 가이드」와 「효율적인 공부법 통합 완벽 가이드」를 기준으로 했습니다. 코어 먼저 → 기존 지식(C++·TCP)과 연결 → 사전 질문(생산적 실패) → 본문 → 실무 시나리오 → 인출 연습 순서입니다.

> **누구를 위해:** C++로 TCP/소켓 게임 서버를 만들어 왔지만 인프라 경험은 거의 없는 개발자. 공부 방법은 [📚 학습 가이드](00-학습-가이드/index.md)를 보세요.
