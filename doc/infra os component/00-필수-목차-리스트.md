## 2. 선별 기준 (2단계)

**포함:** "컨테이너와 쿠버네티스는 결국 리눅스 커널 기능 위의 프로세스"라는 사슬을 설명하는 데 빠지면 안 되는 개념 — 커널/프로세스/메모리/파일/네트워크의 동작, 컨테이너를 만드는 커널 프리미티브, Docker·containerd·runc의 구성 요소, 쿠버네티스 컨트롤 플레인·노드 컴포넌트와 그들이 리눅스에 만드는 결과(iptables 규칙, cgroup, veth, mount).

**제외:** Windows 비교, 버전별 변경 이력, 커스텀 확장 개발(CRD·오퍼레이터·client-go·웹훅 작성), 서비스 메시·eBPF 데이터플레인 심화, Swarm 오버레이, Rootless·IPv6 세부, EKS·Terraform·Helm·GitOps·관측성 스택 구축, 시험 매핑, 스레드 동기화의 언어별 세부(CPU 캐시 등).

## 3. 통합 필수 목차 (3단계)

### 1부. 리눅스 OS 구성 요소
1. 커널, 시스템 콜, 스케줄러 — `linux/02`, `K8s textbook 19.1`
2. 프로세스 — fork/exec, PID 1, 좀비, 세션, 자격 증명, ulimit, IPC — `linux/03`
3. 시그널 — SIGTERM/SIGKILL, PID 1 함정, 종료 프로토콜 — `linux/08`
4. 메모리 — 가상 메모리, 오버커밋, OOM Killer, 페이지 캐시, mmap, 스왑 — `linux/05`
5. 파일시스템과 I/O — fd 3계층, VFS, 마운트, 버퍼링, 링크, inotify — `linux/07`
6. 네트워크 스택 — 소켓, TCP 상태, TIME_WAIT, epoll, Unix 소켓, DNS — `linux/06`
7. 스레드와 동시성 — 스레드=태스크, futex, 데드락, 적정 스레드 수 — `linux/04`
8. 진단 도구 — /proc, strace, ss, perf, 문제 유형별 첫 명령 — `linux/09`

### 2부. 컨테이너를 만드는 커널 기능과 Docker 구성 요소
9. 네임스페이스 — 8종, /proc/PID/ns — `docker-fundamental/02`
10. cgroup v1/v2 — 컨트롤러, 옵션 매핑, OOM — `docker-fundamental/03`
11. 이미지·레이어·overlayfs·콘텐츠 주소화 — `docker-fundamental/06`
12. OCI 표준과 런타임 — Image/Runtime Spec, runc, crun, gVisor, Kata — `docker-fundamental/04`
13. Docker 아키텍처 — docker CLI·dockerd·containerd·shim·runc, 프로세스 트리, containerd 내부 — `docker-fundamental/01·05·07`
14. 볼륨·바인드 마운트·tmpfs — `docker-fundamental/06.6`
15. 빌드 — BuildKit과 Dockerfile의 핵심 — `docker-fundamental/08·09`
16. Docker 네트워크 — CNM, 브리지·veth, iptables NAT, docker-proxy, 내장 DNS, 네트워크 모드, nftables — `docker-fundamental/11·12·14·15·16`
17. 컨테이너를 손으로 만들기 — 리눅스 프리미티브 총정리, pause, capability·seccomp — `K8s textbook 19`

### 3부. 쿠버네티스 구성 요소
18. 클러스터 아키텍처 총론 — 선언적 상태, 조정 루프, 요청의 여정 — `K8s internals 01`, `qustion 02심화 01`
19. kube-apiserver — 필터 체인, 인증·인가·어드미션, 버전 변환, watch — `K8s internals 02`, `textbook 17·21`
20. etcd — Raft, MVCC, watch, 백업 — `K8s internals 03`, `textbook 22`
21. kube-scheduler — 필터·스코어, 큐, 선점, 테인트·어피니티 — `K8s internals 04`, `textbook 15`
22. 컨트롤러 매니저 — Informer, Workqueue, 조정, 리더 선출, GC·finalizer — `K8s internals 05`, `textbook 21`
23. kubelet과 컨테이너 런타임 — 동기화 루프, CRI, static Pod, 노드 상태·축출 — `K8s internals 06`, `textbook 20`
24. 오브젝트 모델과 워크로드 — Pod, ReplicaSet/Deployment/StatefulSet/DaemonSet/Job, 라벨 — `textbook 4·5·8`
25. Pod 생명주기와 리소스 — 프로브, 종료 시퀀스, requests/limits→cgroup, QoS, 스로틀링·OOM, 축출 — `textbook 6·14`
26. 쿠버네티스 네트워크 모델과 CNI — 4대 요구사항, CNI 동작, Pod CIDR, 오버레이 vs 라우팅 — `K8s internals 13`, `textbook 23`
27. Service와 kube-proxy — EndpointSlice, iptables/IPVS/nftables 데이터플레인 — `K8s internals 14·15`
28. CoreDNS와 외부 노출 — resolv.conf/ndots, Ingress·Gateway, NetworkPolicy 기초 — `K8s internals 16~18`
29. 스토리지 — PV/PVC/StorageClass, CSI, kubelet 마운트 — `textbook 12`
30. 설정·보안 — ConfigMap·Secret이 파일/환경변수가 되는 과정, ServiceAccount, RBAC, securityContext — `textbook 7·17·18`
31. 계층 종합 — Docker 명령 ↔ 쿠버네티스 ↔ 리눅스 대응표와 장애 진단 지도 — 전체 + `K8s internals 부록`
