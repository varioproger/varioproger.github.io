## 구축 흐름 요약

1. **Docker 기반 마련**: VM(Ubuntu) 준비 → Docker 엔진 설치 → 관리도구(Portainer)
2. **컨테이너 운용**: 이미지/레지스트리 → 네트워크 → 자원 제한 → 볼륨 → Dockerfile
3. **멀티 컨테이너/오케스트레이션(Docker)**: Compose → Swarm → CI(GitHub Actions) → ECS/Jenkins 프로젝트
4. **Kubernetes 클러스터 구축**: kubeadm init/join + CNI(Calico) → 관리도구
5. **Kubernetes 워크로드 배포**: Pod → Service → Volume → ConfigMap/Secret → Deployment 등
6. **Kubernetes 운영/보안**: Namespace·RBAC·NetworkPolicy → 노드 유지보수·업그레이드
