# Docker와 Kubernetes로 인프라 구축할 때 알아야 하는 필수 이론 지식

Docker와 Kubernetes로 처음 인프라를 구축하는 입문자가 **명령어를 외우기 전에 반드시 이해해야 하는 선수 지식**만 골라 정리한 책입니다.
깊은 내부 구현은 빼고, "왜 이렇게 동작하는가"를 이해할 수 있는 수준까지만 다룹니다.

## 이 책이 만들어진 방식

1. 참고 자료 폴더(Docker 내부구조, Kubernetes 종합서, Kubernetes 질문집, Kubernetes 내부·네트워크, 리눅스 OS, CLI 가이드 PDF)의 목차를 모두 확인했습니다.
2. 입문자가 처음 인프라를 구축할 때 필수인지 기준으로 항목을 골랐습니다. (버전별 변경 이력, 런타임 내부 구현, CRD·오퍼레이터·client-go 같은 확장 개발, eBPF 등은 제외)
3. 고른 항목을 하나의 목차로 만들고, 각 장을 원문 내용에 근거해 집필했습니다.
4. 각 부마다 검증 에이전트가 원고의 모든 절을 원문과 대조했습니다. 원문에 근거가 없는 내용은 삭제하거나 원문 내용으로 교체했고, 남긴 보충 설명은 `[보충]` 표시로 일관되게 구분했습니다.

> **표기 규칙** — 본문 중 `> **[보충]**`으로 시작하는 인용 블록은 원문 자료에 직접 근거가 없는 입문자용 보충 설명입니다. 그 외 본문은 원문에서 가져온 내용입니다.

## 이 판에서 바뀐 점

- **누구를 위해:** C++로 TCP/소켓 게임 서버를 만들어 왔지만 인프라 경험은 거의 없는 개발자가, 실무 구축 전에 알아야 할 이론을 익히도록 다시 썼습니다.
- **장마다:** 🎮 게임 서버 개발자에게 → 코어(이것만은 100%) → C++·TCP 서버 경험과의 비교 표 → 코어별 본문 → 실무 시나리오 → 인출 연습 순서입니다. 원문의 사실·명령어·출처 표기는 모두 유지했습니다.
- **순서:** "인프라 전체 그림"을 맨 앞(1장)으로 옮겨 지도를 먼저 보고, 리눅스부터 위로 쌓아 올라갑니다. 공부 방법은 [📚 학습 가이드](00-학습-가이드/index.md)에 있습니다.
