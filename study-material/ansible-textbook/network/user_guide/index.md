# Network Advanced Topics

Once you have mastered the basics of network automation with Ansible, as presented in [Network Getting Started](../getting_started/index.md), use this guide understand platform-specific details, optimization, and troubleshooting tips for Ansible for network automation.

**Who should use this guide?**

This guide is intended for network engineers using Ansible for automation. It covers advanced topics. If you understand networks and Ansible, this guide is for you. You may read through the entire guide if you choose, or use the links below to find the specific information you need.

If you're new to Ansible, or new to using Ansible for network automation, start with the [Network Getting Started](../getting_started/index.md).
