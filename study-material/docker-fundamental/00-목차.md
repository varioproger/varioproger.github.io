# Docker 내부구조 · 프레임워크 · 네트워크 완전 정복

> Docker를 "명령어를 아는" 수준을 넘어 "왜 이렇게 동작하는가"까지 이해하기 위한 교재입니다.
> 컨테이너를 실행하는 커널 메커니즘부터 이미지를 빌드하는 프레임워크, 컨테이너가 서로 통신하는 네트워크 스택까지
> 세 축을 중심으로 다룹니다. 2026년 9월 기준 최신 안정 버전(Docker Engine 29.8.1, containerd 2.3.x, runc 1.5.x,
> BuildKit 0.17+)을 기준으로 서술하며, 과거 버전과 달라진 지점은 명시적으로 표시합니다.

## 이 교재의 범위

이 책은 "Docker 입문서"가 아닙니다. `docker run`, `docker build`가 무엇을 하는 명령인지 아는 독자를 대상으로,
그 명령 뒤에서 실제로 무슨 일이 일어나는지를 파고듭니다. 설치 방법이나 기초 CLI 튜토리얼은 다루지 않습니다.

## 참고 사항

- 예제 명령은 Linux(커널 5.15+ 또는 6.x) 환경, Docker Engine 29.x 기준으로 검증되었습니다.
- Docker Desktop(macOS/Windows) 고유의 VM 계층은 이 책의 핵심 논의 대상이 아닙니다. 리눅스 호스트에서의
  네이티브 동작을 기준으로 설명하며, Desktop 환경과의 차이는 필요한 곳에서 별도로 언급합니다.
- 각 장 말미의 "핵심 요약"과 "실습"은 이해를 점검하기 위한 것으로, 실제 운영 환경 적용 전 반드시
  본인 환경에서 재현·검증하시기 바랍니다.
