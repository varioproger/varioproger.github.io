# Part I. 네트워크 통신의 기초

> HTTP 보안을 이해하는 데 반드시 필요한 하위 계층의 성질만 골라, 뒤의 장들이 인용할 수 있는 형태로 정리한다.
> 각 절은 "이 성질이 나중에 어떤 취약점의 전제가 되는가"를 명시하며 끝난다.

## 1장. 인터넷의 계층 구조: 패킷은 어떻게 목적지에 도달하는가

- 1.1 계층으로 나눈다는 것 — 관심사의 분리가 만든 것과 감춘 것
- 1.2 TCP/IP 4계층과 OSI 7계층의 대응
- 1.3 캡슐화 — 하나의 HTTP 요청이 프레임이 되기까지
  - 1.3.1 HTTP 메시지 → TCP 세그먼트 → IP 패킷 → 링크 프레임
  - 1.3.2 MTU, 단편화, MSS
- 1.4 계층 경계는 신뢰 경계가 아니다 — 하위 계층이 상위 계층을 보호해주지 않는 이유
- 1.5 대역폭과 지연 — 두 개의 독립적인 제약
  - 1.5.1 속도는 기능이다
  - 1.5.2 지연의 구성 요소 — 전파, 전송, 처리, 큐잉
  - 1.5.3 빛의 속도와 전파 지연 / 라스트마일 지연
  - 1.5.4 코어망과 네트워크 엣지의 대역폭
- 1.6 RTT가 모든 것의 단위인 이유
- 1.7 마지막 구간의 특성 — 유선, WiFi, 셀룰러
  - 1.7.1 무선 네트워크의 성능 기초 — 대역폭, 신호 강도, 변조
  - 1.7.2 WiFi — 이더넷에서 무선 LAN으로, 패킷 손실의 성격 차이
  - 1.7.3 셀룰러 — 라디오 자원 제어기(RRC)와 상태 전이가 만드는 지연
  - 1.7.4 이 특성이 프로토콜 설계와 보안 판단에 미치는 영향
- 1.8 하위 계층 공격의 지형 — 스니핑, 스푸핑, 중간자가 성립하는 조건

## 2장. IP, 라우팅, 그리고 이름: DNS

- 2.1 IP 주소와 라우팅의 기본 — 최선 노력(best-effort) 전달의 의미
- 2.2 왜 이름이 필요한가 — 호스트명, 포트, 그리고 소켓 주소

- 2.4 DNS 지연은 요청 지연의 일부다 — 첫 요청의 비용 구조
- 2.5 TTL과 DNS 캐싱 — 누가, 얼마나 오래 기억하는가
- 2.6 DNS를 이용한 트래픽 분산 — 라운드로빈, anycast, GeoDNS
- 2.7 이름과 신원은 다르다 — 이름 해석의 결과를 신뢰할 수 있는가

- 2.9 호스트명 기반 가상 호스팅의 전제

## 45장. 안전한 실패 처리와 가용성 설계

- 47.11 마이크로서비스의 로깅 — 집계 로그의 무결성, 추적성, 도메인 지향 로거 API로 기밀성 확보
