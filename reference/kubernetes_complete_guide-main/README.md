# Kubernetes Complete Guide

4권의 원서를 분석해 **입문자 → 실무자** 전 범위를 한 권으로 재구성한 쿠버네티스 종합서.

- 언어: 한국어
- 분량: 장당 3~5천자 (본문 + YAML 예제 + 실습)
- 구성: 7부 32장 + 부록 5개 + 아키텍처 도해 6종

## 전체 목차

### 1부. 쿠버네티스로 가는 길 (입문)
1. **왜 쿠버네티스인가** — 인프라 드리프트, 선언적 상태와 조정 루프, 아키텍처 개관, 도입하지 말아야 할 경우
2. **컨테이너의 이해** — 이미지·레이어·OCI, namespace/cgroup/capability, 런타임 계보와 CRI
3. **첫 클러스터 만들기** — kind 3노드 클러스터, kubectl 기본기, YAML 작성 규칙, 첫 배포

### 2부. 워크로드 실행하기 (기본)
4. **쿠버네티스 API 오브젝트 모델** — API 그룹/버전, 공통 구조, 라벨과 셀렉터, Event
5. **Pod: 최소 배포 단위** — 왜 Pod인가, 멀티 컨테이너, Init 컨테이너, 디자인 패턴
6. **Pod 생명주기와 헬스 관리** — status와 컨디션, 프로브 설계, 훅과 graceful shutdown
7. **설정과 시크릿** — ConfigMap, Secret, Downward API, 외부 시크릿 관리
8. **워크로드 컨트롤러** — Deployment, StatefulSet, DaemonSet, Job/CronJob

### 3부. 애플리케이션 노출과 데이터 (기본~중급)
9. **서비스와 클러스터 네트워킹 기초** — Service 타입, EndpointSlice, kube-proxy
10. **DNS와 서비스 디스커버리** — CoreDNS, FQDN 규칙, resolv.conf와 ndots
11. **인그레스와 외부 트래픽 라우팅** — IngressController, TLS, Gateway API, 서비스 메시
12. **스토리지: 볼륨에서 CSI까지** — PV/PVC/StorageClass, 동적 프로비저닝, CSI

### 4부. 클러스터 운영 (중급)
13. **네임스페이스와 멀티테넌시** — ResourceQuota, LimitRange, 격리 패턴
14. **리소스 관리와 QoS** — requests/limits, QoS 클래스, 스로틀링과 축출
15. **고급 스케줄링** — 어피니티, 테인트/톨러레이션, 토폴로지 분산, 우선순위
16. **오토스케일링** — HPA, VPA, Cluster Autoscaler/Karpenter, KEDA
17. **인증, 인가, 어드미션** — 요청 파이프라인, RBAC, 워크로드 아이덴티티
18. **워크로드 보안** — securityContext, Pod Security Admission, NetworkPolicy, 공급망 보안

### 5부. 내부 동작 파헤치기 (심화)
19. **Pod를 밑바닥부터 만들어 보기** — 리눅스 프리미티브, pause 컨테이너, cgroup 실습
20. **kubelet과 노드** — 동기화 루프, CRI, static Pod, 축출
21. **컨트롤 플레인의 핵심** — apiserver, controller-manager, 컨트롤러 패턴, 리더 선출
22. **etcd** — Raft, 키 구조와 watch, CAP, 백업과 복구
23. **CNI와 대규모 네트워크 트러블슈팅** — CNI 스펙, Calico/Antrea, iptables 해부, 진단 플로차트

### 6부. 쿠버네티스 확장하기 (심화 / 개발자)
24. **확장 지점 지도** — 확장 패턴 분류, 컨트롤러 vs 오퍼레이터, 선택 가이드
25. **client-go 기초** — ClientSet, Informer, 캐시, 워크큐, API Machinery
26. **커스텀 리소스** — CRD 정의, 스키마 검증, 서브리소스, 버저닝
27. **오퍼레이터 만들기** — 코드 생성, sample-controller, Kubebuilder, Operator SDK
28. **어드미션 웹훅과 커스텀 API 서버** — Mutating/Validating 웹훅, 어그리게이션 계층

### 7부. 프로덕션 플레이북 (실무)
29. **매니지드 쿠버네티스 실전** — GKE/EKS/AKS 비교, IaC로 클러스터 관리
30. **패키징과 배포 파이프라인** — Helm, Kustomize, Carvel, GitOps(Argo CD/Flux)
31. **관측성** — Prometheus, 로깅, OpenTelemetry, SLI/SLO 기반 알림
32. **클러스터 라이프사이클과 장애 대응** — HA, 업그레이드, 백업/DR, 트러블슈팅 플레이북

### 부록
- **A. kubectl 치트시트** — 명령 레퍼런스, JSONPath, 진단 원라이너, 시험용 속도 팁
- **B. 쿠버네티스 아키텍처 도해** — 그림 6종으로 보는 구조: 클러스터 구성, Pod 생성 흐름, Pod 내부, 오브젝트 관계, 네트워크 경로, 생명주기
- **C. 오브젝트 레퍼런스** — 주요 오브젝트별 "무엇을 위한 것인가 → 언제 쓰는가 → 최소 YAML → 함정", 선택 결정 트리
- **D. CKA / CKAD 시험 도메인 매핑** — 시험 항목 ↔ 장·절 대응, 학습 계획, 당일 전략
- **E. 용어집과 더 읽을거리** — 한영 용어 대조, 원서·문서·도구 목록

## 실습 환경

전 장의 실습은 다음 환경을 전제로 한다.

```bash
docker version          # 24.x 이상
kind version            # v0.23 이상
kubectl version --client   # 클러스터와 마이너 ±1
```

실습 클러스터는 3장에서 만드는 `k8s-guide`(컨트롤 플레인 1 + 워커 2)를 계속 사용한다.
