## 원본 보존 검증

원본 ZIP의 50개 파일을 편집 전 바이트와 비교해 전부 일치함을 확인했다. 그중 Markdown은 39개다. 실습의 Markdown 안내 외 실행 파일은 이동 후에도 편집 전 바이트와 일치한다.

장 번호·문서 링크·이동 안내는 새 순서에 맞게 수정했다. 원래 문장과 이전 파일명까지 필요한 경우 ZIP에서 그대로 확인할 수 있다. 본문에서 언급한 PDF 7개는 현재 저장소에 없어 기존 절대 링크를 원자료 경로 표기로 바꿨다. PDF 내용을 삭제하거나 새로 분석한 것은 아니다.

## 재구성 후 검사

- Markdown 47개에서 로컬 링크 583개의 대상 파일·문서 앵커를 확인했다. 끊어진 링크는 없었다.
- 기초 10장·심화 21장의 번호가 연속이고, 최종 문제집을 포함한 35개 장의 이전·다음 링크가 상단과 하단에서 순서대로 연결되는지 확인했다.
- 코드·도식 블록 127개의 닫힘을 확인했다. 기존 122개 블록은 전부 보존했고, 기존 예제의 변경은 실습 진입 경로를 현재 폴더 구조로 바꾼 부분뿐이다.
- 번호·링크·진행 안내를 변환한 기존 본문의 모든 비어 있지 않은 줄이 최종 문서에 남아 있는지 확인했다. 이후 교정한 참조 번호와 진행 문장도 검사에 반영했다.
- 원본 ZIP 50개 파일의 SHA-256과 저장된 바이트를 편집 전 원본과 대조했고, 실습 실행 파일 11개는 이동 후에도 원본과 일치했다.

이번 검사는 문서 구조·참조·내용 보존 검사다. Mermaid 화면 렌더링, Terraform 예제 실행, Docker 빌드, 실제 Kubernetes/EKS 적용은 수행하지 않았다. 기존 안내문에 적힌 과거 실습 검증 결과는 당시 기록으로 보존했다.
