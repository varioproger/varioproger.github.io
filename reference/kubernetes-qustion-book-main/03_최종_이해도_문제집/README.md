# Terraform · Docker · Kubernetes · EKS 최종 이해도 문제집

이 문제집은 용어 암기보다 **전체 구조를 설명하고, 상태를 예측하고, 장애 원인을 증거로 좁히는 능력**을 확인한다. 기존 교재를 1회 이상 읽은 뒤 자료를 덮고 푼다.

총점은 100점이다. 1–4부 80점은 비교적 명확한 핵심 개념을 평가하고, 5부 20점은 전체 구조를 연결하는 능력을 평가한다.

## 푸는 규칙

1. 첫 시도에는 교재·검색·실습 환경을 보지 않는다.
2. “Kubernetes가 한다”에서 멈추지 않고 가능하면 **누가 → 무엇을 보고 → 무엇을 바꾸는가**로 답한다.
3. 장애 문제에는 원인 하나만 단정하지 말고, 첫 가설과 이를 확인할 증거를 쓴다.
4. 답을 모두 작성한 뒤에만 해설을 연다.
5. 틀린 문제는 정답을 베껴 쓰지 않고, 연결 그림이나 세 문장 설명으로 다시 푼다.

## 점수 해석

| 점수 | 현재 이해도 | 다음 행동 |
|---:|---|---|
| 90–100 | 전체 구조와 주요 실패 경계를 안정적으로 설명 | 종합 실습과 실제 설계 검토로 이동 |
| 75–89 | 큰 구조는 이해했으며 일부 내부 연결이 약함 | 틀린 영역만 다시 읽고 장애 문제 재풀이 |
| 60–74 | 용어는 알지만 흐름 중간의 주체가 섞임 | 기초 01·05·06·08장으로 전체 흐름 다시 그리기 |
| 0–59 | 개별 도구가 분리된 암기로 남아 있음 | 큰 그림부터 순서대로 재학습 |

점수는 자격 인증이 아닌 자기 점검 기준이다. 75점 이상이어도 4부 장애 진단이 절반 미만이면 운영 문제를 더 연습한다. 5부에서 보안·데이터·복구를 빠뜨렸다면 배포 성공만 이해한 상태이므로 관련 장을 보완한다.
