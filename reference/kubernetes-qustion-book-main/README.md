## 먼저 구분할 핵심

Docker는 앱 이미지를 만들고 실행하는 도구를 제공한다. Kubernetes는 Pod의 배치·실행 상태를 유지하며, EKS는 AWS의 관리형 Kubernetes 서비스다. Terraform은 지정한 기반 자원과 정책을 API로 생성·변경한다.

**Pod가 EC2 위에서 실행된다고 Pod가 늘 때마다 Terraform을 수정하는 것은 아니다.** 기존 Node에 여유가 있으면 Pod만 늘어난다. Node 자동 확장이 구성되어 있으면 정책 안의 EC2 증설은 해당 자동화가 처리한다. Terraform이 소유하는 노드 수량·상한·네트워크·권한 등을 변경할 때는 Terraform을 사용한다. 기초 02장에서 역할을 배우고 07장에서 경우별로 판단한다.
