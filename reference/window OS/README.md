# 프로그래머를 위한 OS 필수 지식

> "OS를 몰라도 코드는 돌아간다. 하지만 왜 느려지는지, 왜 멈추는지, 왜 가끔 죽는지는 OS를 알아야 보인다."

이 책은 애플리케이션/서버/게임/시스템 프로그래머가 실무에서 마주치는 성능 문제, 동시성 버그, 메모리 이슈, 네트워크 병목을 이해하고 디버깅할 수 있도록, **운영체제 지식 중 실제로 쓰이는 부분만** 선별해서 정리한 것입니다.

이 폴더에 있는 참고 자료(*Windows Internals Part 1/2*, *Windows via C/C++*)를 기반으로 Windows를 중심 사례로 쓰되, 리눅스/POSIX와의 차이를 각 장의 "다른 OS에서는" 절에서 짚어줍니다. 개념 자체는 플랫폼에 무관하게 통용됩니다.

## 대상 독자

- C/C++, C#, Java, Go, Rust, Python 등으로 실무 코드를 짜지만 "커널이 뭘 하는지"는 흐릿한 개발자
- "왜 이 프로세스가 메모리를 안 돌려주지?", "왜 스레드가 데드락에 걸렸지?", "왜 소켓이 느리지?" 같은 질문에 감으로만 답해온 개발자
- CS 전공 OS 수업을 들었지만 실무 코드/도구와 연결이 안 되는 개발자

## 이 책을 읽는 방법

각 장은 독립적으로 읽을 수 있지만, 순서대로 읽으면 "프로세스 → 스레드 → 메모리 → 네트워크"로 자연스럽게 개념이 쌓입니다. 각 장 끝에는 **실전 체크리스트**(면접/디버깅 상황에서 바로 쓸 수 있는 질문 목록)를 넣었습니다.
