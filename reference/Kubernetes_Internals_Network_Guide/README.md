# Kubernetes 내부 구조·프레임워크·네트워크 심화

**쿠버네티스의 내부 구성(컨트롤 플레인·노드 내부 동작), 확장 프레임워크(client-go·CRD·오퍼레이터·어드미션), 네트워크(서비스·CNI·데이터플레인·eBPF)** 세 축을 깊이 파고드는 전문 교재.

`Kubernetes_Complete_Guide`가 입문부터 실무까지 전 범위를 다루는 종합서라면, 이 교재는 그중 **내부 동작·확장·네트워크** 세 영역만 골라 훨씬 깊게 다룬다. 이미 쿠버네티스 오브젝트와 기본 운영에 익숙한 독자(위 종합서의 1~4부, 또는 동급 경험)를 대상으로 한다.

- 언어: 한국어
- 분량: 장당 4~7천자 (본문 + 다이어그램 + 코드/YAML 예제 + 실습)
- 구성: 3부 19장 + 부록 2개

## 전체 목차

### 1부. 내부 아키텍처
1. **클러스터 아키텍처 총론** — 선언적 상태와 조정 루프, 컨트롤 플레인·노드 컴포넌트 지도, 요청 하나의 전체 여정
2. **kube-apiserver 내부 구조** — 필터 체인, 버전 변환 허브 모델, 어그리게이션 계층, watch cache와 APF
3. **etcd와 데이터 계층** — Raft 합의, 키 구조와 MVCC, watch 구현, 압축·방어·백업/복구
4. **kube-scheduler 내부** — 스케줄링 프레임워크(Filter/Score/Bind), 확장점, 우선순위·선점·스케줄링 큐
5. **컨트롤러 매니저와 컨트롤러 패턴** — Informer/Workqueue 내부, 조정 루프 원칙, 리더 선출, 가비지 컬렉터
6. **kubelet·컨테이너 런타임·kube-proxy 개요** — 노드 쪽 삼각편대, 동기화 루프, CRI, static Pod, 서비스 프록시 개관

### 2부. 프레임워크
7. **확장 지점 지도** — 쿠버네티스를 확장하는 8가지 방법과 선택 기준
8. **client-go와 API Machinery** — ClientSet, Informer/Lister/Indexer, Workqueue, Scheme/Codec
9. **CRD와 커스텀 리소스 프레임워크** — OpenAPI 스키마 검증, 서브리소스, 버저닝과 컨버전 웹훅
10. **오퍼레이터 프레임워크** — controller-runtime, Kubebuilder/Operator SDK, 조정 로직 설계 패턴
11. **어드미션 웹훅과 정책 프레임워크** — Mutating/Validating 웹훅 구현, CEL 기반 ValidatingAdmissionPolicy
12. **스케줄러 플러그인과 커스텀 API 서버** — 스케줄러 프레임워크 플러그인 작성, 어그리게이션 API 서버(APIService)

### 3부. 네트워크
13. **네트워킹 모델과 CNI 스펙** — 쿠버네티스 네트워크 모델의 4대 요구사항, CNI 인터페이스, 플러그인 생태계
14. **Service와 EndpointSlice** — Service 타입별 내부 동작, EndpointSlice 구조, 서비스 디스커버리
15. **kube-proxy 데이터플레인 해부** — iptables 체인 상세, IPVS 내부 구조, 두 모드 비교
16. **DNS와 서비스 디스커버리** — CoreDNS 아키텍처와 플러그인 체인, FQDN·ndots, 트러블슈팅
17. **Ingress·Gateway API·서비스 메시** — L7 라우팅, TLS 종료, mTLS, 사이드카/앰비언트 메시
18. **NetworkPolicy와 네트워크 보안** — 정책 모델, CNI별 구현 차이, 제로 트러스트 네트워킹
19. **eBPF 데이터플레인과 대규모 네트워크 트러블슈팅** — Cilium/XDP 내부, 진단 플로차트, 패킷 캡처 실전

### 부록

## 이 교재의 성격

- **`Kubernetes_Complete_Guide`와 대상 독자가 다르다.** 그 책의 5부(내부 동작)·6부(확장)·3부(네트워킹)를 이미 읽었거나 동급 지식이 있다는 전제 위에서, 같은 주제를 훨씬 깊게(소스 레벨 메커니즘, 내부 자료구조, 프로토콜 상세) 다룬다. 내용은 겹치지 않도록 새로 집필했다.
- 모든 예제는 `kind` 기반 로컬 클러스터를 전제로 하며, 필요한 경우 CNI를 Calico/Cilium으로 교체하는 절차를 함께 안내한다.
- 각 장은 학습목표 → 본문(다이어그램/코드) → 실습 → 요약 순으로 구성된다.
